# WhisperBridge identity

The original mark turns a waveform into three text lines inside a speech bubble. It expresses recorded speech becoming prompt text. Deep teal gives the mark a quiet technical character; mint distinguishes the audio side. The icon remains understandable without color because waveform and text have different shapes.

- `logo.svg`: editable horizontal identity on a pale background; 840 × 240.
- `icon.svg`: square application concept; 256 × 256. Final platform icon exports remain a packaging task.
- `icon-mono.svg`: one-color mark for monochrome use.
- `preview.html`: light/dark presentation and small-size inspection.

Palette: deep teal #143A43, mint #67DDD0, white #FFFFFF, pale background #F4F7F8, secondary text #46616A. System sans-serif wordmark avoids an external font download; exported brand artwork should outline lettering if identical typography across platforms is required. Keep clear space of one text-line height around the mark. Use the mark alone below 240 px lockup width; use the simplified mono version at 16 px. Do not stretch, rotate, add shadows, or imply official LM Studio/OpenAI endorsement.

Created directly as vector geometry, with no external image assets or generated bitmap dependency. The working name has not been checked for trademark availability.
